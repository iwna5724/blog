# 블로그를 시작하며

드디어 나만의 블로그를 만들었습니다! 🎉

## 왜 블로그를 만들었나요?

여러 플랫폼에 의존하지 않고, 완전한 자율성을 가진 블로그를 운영하고 싶었습니다.

### 주요 기능

- **마크다운 기반**: 쉽고 빠른 글 작성
- **GitHub 저장**: 모든 글이 버전 관리됨
- **자동 배포**: GitHub Actions로 자동 빌드
- **완전한 통제**: 디자인부터 기능까지 모두 커스터마이징 가능

## 앞으로의 계획

꾸준히 글을 작성하며 블로그를 발전시켜 나갈 예정입니다.

```javascript
// 간단한 코드 예제
console.log('Hello, Blog!');
```

앞으로 많은 관심 부탁드립니다!
