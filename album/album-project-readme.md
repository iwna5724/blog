# 앨범 및 타이틀 프로젝트

## 개요

15×15 그리드 구조를 사용하여 이미지 앨범과 타이틀 화면을 동시에 관리할 수 있는 웹 기반 도구입니다. 각 셀에 이미지를 배치하고, 텍스트 오버레이를 추가하여 고해상도 PNG 파일로 내보낼 수 있습니다.

## 주요 기능

### 1. 그리드 구조
- **전체 크기**: 15×15 (총 225개 셀)
- **중앙 셀**: 5×5 크기 (300px × 300px), ID 0으로 관리
- **일반 셀**: 200개, ID 1~200
- **셀 크기**: 각 60px × 60px

### 2. 이중 뷰 시스템

#### 앨범 (Album)
- 각 셀에 업로드된 이미지를 그대로 표시
- 이미지는 셀에 꽉 차게 배치 (object-fit: cover)
- 테두리나 효과 없이 순수 이미지만 표시

#### 타이틀 (Title)
- 앨범과 동일한 이미지 배치
- 각 셀 위에 반투명 검정 오버레이 (투명도 60%)
- 오버레이 위에 흰색 텍스트 표시
- 텍스트는 리스트에서 입력한 문자열 사용

### 3. 데이터 관리

#### 3개 영역 시스템
리스트는 3개의 독립적인 영역으로 분리됩니다:

- **영역 1**: ID 1 ~ n (기본값: 67)
  - 파랑-보라 그라데이션 헤더
- **영역 2**: ID (n+1) ~ m (기본값: 68~134)
  - 핑크-빨강 그라데이션 헤더
- **영역 3**: ID (m+1) ~ 200 (기본값: 135~200)
  - 파랑-청록 그라데이션 헤더

영역 경계는 상단 컨트롤에서 자유롭게 조정 가능합니다.

#### 리스트 구조
각 행은 다음 정보를 포함합니다:
- **ID**: 셀의 고유 번호 (0~200)
- **이미지**: 로컬 파일 업로드 (클릭하여 선택)
- **문자열**: 타이틀 오버레이에 표시될 텍스트
- **조작**: 행 추가(+) / 삭제(-) 버튼

### 4. 행 조작 기능

#### 행 추가
- 특정 행의 `+` 버튼 클릭
- 해당 행 다음에 새 행이 삽입됨
- 이후 모든 ID가 자동으로 1씩 증가
- 그리드의 이미지도 자동 동기화

#### 행 삭제
- 특정 행의 `-` 버튼 클릭
- 해당 행 삭제
- 이후 모든 ID가 자동으로 1씩 감소
- 그리드의 이미지도 자동 동기화

### 5. 파일 관리

#### PNG 내보내기
- **앨범 PNG 저장**: 순수 이미지 그리드를 고해상도 PNG로 저장
- **타이틀 PNG 저장**: 오버레이와 텍스트가 포함된 그리드를 PNG로 저장
- 출력 해상도: 자동으로 고해상도로 스케일링 (약 4008px 기준)

#### JSON 저장/불러오기
저장되는 정보:
```json
{
  "cells": [
    {
      "id": 0,
      "img": "data:image/png;base64,...",
      "text": "텍스트 내용"
    },
    ...
  ],
  "region1End": 67,
  "region2End": 134
}
```

- **JSON 저장**: 모든 셀 데이터와 영역 경계 정보를 파일로 저장
- **JSON 불러오기**: 저장된 파일을 불러와 작업 복원

## 사용 방법

### 1. 이미지 추가
1. 리스트에서 원하는 셀의 '이미지 없음' 영역 클릭
2. 로컬 이미지 파일 선택
3. 이미지가 자동으로 앨범과 타이틀 그리드에 반영됨

### 2. 텍스트 입력
1. 리스트의 '문자열' 열에 있는 텍스트 영역에 입력
2. 입력한 텍스트가 실시간으로 타이틀 그리드에 반영됨
3. 개행(\n)도 지원됨

### 3. 영역 조정
1. 상단 '영역 1 끝', '영역 2 끝' 입력 필드에 원하는 ID 입력
2. '영역 적용' 버튼 클릭
3. 리스트가 새로운 영역 구조로 재배치됨

### 4. 작업 저장
1. 하단 '💾 JSON 저장' 버튼 클릭
2. `album_data.json` 파일 다운로드
3. 나중에 '📂 JSON 불러오기'로 복원 가능

### 5. 결과물 내보내기
1. '📷 앨범 PNG 저장' 또는 '🎬 타이틀 PNG 저장' 클릭
2. 고해상도 PNG 파일 다운로드

## 기술 스택

- **HTML5**: 기본 구조
- **CSS3**: 스타일링 및 그리드 레이아웃
- **JavaScript (Vanilla)**: 모든 인터랙션 로직
- **html2canvas**: PNG 내보내기 기능
- **Google Fonts**: Nanum Gothic 폰트

## 파일 구조

```
album.html
├── <style>      - 모든 CSS 스타일
├── <body>       - HTML 구조
│   ├── 앨범 컨테이너
│   │   ├── 컨트롤 버튼
│   │   ├── 앨범 그리드 (15×15)
│   │   └── 타이틀 그리드 (15×15)
│   └── 리스트 컨테이너
│       ├── 영역 조정 컨트롤
│       ├── 영역 1 테이블
│       ├── 영역 2 테이블
│       └── 영역 3 테이블
└── <script>     - 모든 JavaScript 로직
```

## 주요 함수

- `createCells()`: 초기 그리드 셀 생성
- `renderList()`: 리스트 테이블 렌더링
- `updateCell(cell)`: 특정 셀의 그리드 업데이트
- `insertRow(index)`: 행 추가 및 ID 재정렬
- `deleteRow(index)`: 행 삭제 및 ID 재정렬
- `updateRegions()`: 영역 경계 변경 적용
- `saveGridAsPNG()`: 그리드를 PNG로 내보내기
- `getRegion(id)`: 특정 ID가 속한 영역 계산

## 데이터 흐름

```
사용자 입력
    ↓
cells 배열 업데이트
    ↓
    ├→ 리스트 테이블 재렌더링
    └→ 그리드 (앨범/타이틀) 업데이트
         ↓
    실시간 UI 반영
```

## 제약사항

- 중앙 셀(ID 0)은 삭제 불가
- 영역 1 끝 < 영역 2 끝 조건 필수
- 영역 범위: 1~200
- 이미지는 Base64로 인코딩되어 저장 (큰 이미지는 파일 크기 증가)

## 활용 사례

- 음악 앨범 커버 디자인
- 영화/비디오 타이틀 시퀀스 제작
- 포토 그리드 콜라주
- 인포그래픽 요소 관리
- 모자이크 아트 프로젝트
