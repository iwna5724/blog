📖 GitHub 토큰 발급 방법

  1. GitHub Settings → Developer settings
  2. Personal access tokens → Tokens (classic) 클릭
  3. "Generate new token" → "Generate new token (classic)" 선택
  4. Note 입력 (예: "Blog Admin")
  5. repo 권한 체크 (전체 선택)
  6. "Generate token" 클릭 후 토큰 복사
